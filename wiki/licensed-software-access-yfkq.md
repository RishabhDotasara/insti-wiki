# Licensed Software Access

IIT Madras provides access to various licensed software tools for academic and research purposes.

The list of available software can be found on the department or HPCE websites.

## Software Access Portal

[HPCE Portal](https://hpce.iitm.ac.in/)

## Access Procedure

To obtain access to licensed software:

1. Go to the HPCE portal
2. Navigate to:
   ```text
   Support → Licensing
   ```
3. Follow the installation or request procedure mentioned there

- Access availability may depend on department permissions.
- Some software may require institute network or VPN access.
- Installation instructions vary depending on the software.
