# ID Card Process

Students must carry a valid IIT Madras ID card during examinations, including:
- quizzes
- midsems
- end-semester exams

## Important Rule

If a student:
- does not have an ID card
- carries a damaged or unreadable ID card

then:
- the exam paper may not be graded
- the student may not be eligible for improvement exams

Which makes the ID card one of the highest ROI objects on campus.

## Lost ID Card

If the ID card is lost:

1. Go to the Academic Section  
   ```text
   4th Floor, Admin Block
   ```

2. Collect the required form

3. Obtain the hostel warden’s signature

4. Pay:

```text
₹500
```

for a new ID card.

## Damaged ID Card Replacement

If the ID card is damaged:

- Pay:

```text
₹250
```

- Hostel warden signature is not required

## Important Notes

- Always carry the ID card during examinations.
- Ensure the card remains readable and undamaged.
- Replacement procedures may take time, so avoid waiting until exam week.

Because discovering your ID card is missing:
```text
10 minutes before endsem
```

is not considered a spiritually enriching experience.
